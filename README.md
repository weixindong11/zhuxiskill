# zhuxi skill

`zhuxi` 是一个面向重要理论文献的 Codex skill。它把朱熹读书法转化为现代学术阅读流程，适合阅读心理学、教育学、社会科学、人文学科中的经典论文、理论文章、综述性理论建构文章和难读章节。

它的目标不是生成普通摘要，而是帮助读者慢读、熟读、精思，并把理论真正读进问题、概念、论证、前人研究和自己的研究/教学场景中。

## 适用场景

- 阅读重要理论文献，而不是只要大意。
- 拆解一篇文章的核心问题、理论对象、关键概念和论证结构。
- 追踪作者如何定义、澄清、比较和辨析概念。
- 分析作者如何承接、批判、补足、转向、整合或重定位前人研究。
- 为英文理论文献生成中文精读脚手架，并保留关键英文术语。
- 将文献转化为 Obsidian 知识库中的理论卡、教学材料、研究问题或复读清单。

## 核心读法

`zhuxi` 的工作流包含这些环节：

1. `读前安顿`：确定阅读单元、阅读目的和深度。
2. `本文纲领`：重建作者自己的问题、主张、概念和论证次序。
3. `前人研究的承接与改造`：分析作者如何使用前人研究，而不是把文献综述当背景列表。
4. `概念澄清与辨析`：保留作者的定义、术语选择、边界划分和近邻概念比较。
5. `逐段涵泳`：逐段说明字面意思、论证作用、文献动作、概念动作、关键词和疑点。
6. `义理脉络`：整理概念关系、理论机制、前提、张力和适用范围。
7. `切己体察`：转化为研究、教学、知识库或经验案例中的可用问题。
8. `再读清单`：列出最值得复读的段落、概念和比较文献。

## 与普通总结的区别

普通总结常常回答：

```text
这篇文章讲了什么？
```

`zhuxi` 更关心：

```text
作者为什么这样安排论证？
作者怎样从前人研究中开出自己的理论空间？
作者在防止哪些概念误读？
哪些词不是随便用的，而是在承担理论功能？
这个理论如何改变我的研究、教学或知识库组织？
```

## 使用方式

安装到 Codex skill 目录后，可以显式调用：

```text
用 $zhuxi 阅读这篇重要理论文献：path/to/paper.md
```

也可以指定阅读重点：

```text
$zhuxi 帮我慢读这篇文章的理论定义段，重点拆解概念边界和作者对前人研究的改造。
```

如果是英文理论文献：

```text
$zhuxi 阅读这篇英文论文。请输出中文精读脚手架，保留关键英文术语，重点分析作者如何定义、澄清和比较概念。
```

## 示例：Sternberg 智慧平衡理论

阅读 Sternberg 1998 年的 *A Balance Theory of Wisdom* 时，`zhuxi` 不只会提取定义：

```text
wisdom = application of tacit knowledge mediated by values toward common good
```

还会追踪作者的概念辨析：

- `wisdom` 不是知识拥有，而是知识应用。
- `tacit knowledge` 不是抽象学术知识，而是情境性的行动知识。
- `practical intelligence` 可以服务自利目标，而 `wisdom` 必须面向共同善。
- `interests` 包含但超出 `points of view`，因为它包括动机和情感差异。
- `balance` 不是一般折中，而是在利益和环境回应之间作复杂权衡。

它也会分析作者如何处理前人研究：

- 承接 Baltes 等人的智慧测量和生命问题传统。
- 将自己 1990 年理论重定位为智慧发展的前因。
- 把本文贡献推进到智慧的过程机制和共同善目标。

## 适合输出的产物

- 理论卡
- 概念辨析表
- 前人研究动作表
- 逐段精读表
- 中文阅读脚手架
- 教学案例设计
- 研究问题清单
- Obsidian wiki 页面草稿

## 注意

这个 skill 不追求一次读完整篇。对于真正重要的理论文献，更推荐先选取定义段、理论框架段、概念辨析段或前人研究转折段进行慢读，再逐步扩展。
